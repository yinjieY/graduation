# 用户需求用例图

```mermaid
usecaseDiagram
actor 企业用户 as Company
actor 监管人员 as Regulator
actor 消费者 as Consumer

rectangle 香干质量安全预警系统 as System {
  (注册/登录) as UCLogin
  (企业认证申请) as UCApply
  (资质审核) as UCReview
  (企业信息管理) as UCCompany
  (批次管理) as UCBatch
  (二维码生成与下载) as UCQR
  (扫码验真/溯源查询) as UCScan
  (扫码日志采集) as UCLog
  (风险评估) as UCRisk
  (预警推送) as UCAlert
  (规则配置) as UCRules
  (二维码冻结/解冻) as UCFrozen
  (区块链存证) as UCChain
  (异常反馈) as UCFeedback
  (预警处置闭环) as UCDispose
  (统计分析/风险态势) as UCAnalytics
}

Company --> UCLogin
Company --> UCApply
Company --> UCCompany
Company --> UCBatch
Company --> UCQR
Company --> UCAlert
Company --> UCDispose

Regulator --> UCReview
Regulator --> UCAlert
Regulator --> UCRules
Regulator --> UCFrozen
Regulator --> UCAnalytics
Regulator --> UCDispose

Consumer --> UCScan
Consumer --> UCFeedback

UCScan ..> UCLog : <<include>>
UCLog ..> UCRisk : <<include>>
UCAlert ..> UCRisk : <<extend>>
UCFrozen ..> UCAlert : <<extend>>
UCChain ..> UCQR : <<include>>
UCChain ..> UCAlert : <<include>>
```
